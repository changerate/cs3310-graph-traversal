# Graph Traversal Algorithm Using DFS 
This algorithm will show you what clusters are in a graph given an input like this: 
4 (1,2) (2,3) (1,4)

## Running 
In the main folder of this project: 

`javac GraphTraveler.java && java GraphTraveler`

Or you can choose your own file (and choose to not compile it every time) by:

`javac GraphTraveler.java`

`java GraphTraveler {your-file-name}`
